# 💐 Raven Beauty – The Subject E-Commerce Platform

A full-featured perfume e-commerce platform built with Flask. "The Subject" allows customers to browse products, manage their cart, place orders, and make payments via mobile money or cash on delivery – all with a clean admin dashboard for store management.

---

## 📖 About Raven Beauty

Raven Beauty is an online perfume store designed for a seamless shopping experience. It combines a user-friendly frontend with a robust Flask backend to handle product inventory, order processing, and customer management.

### Key Functionalities

- **Product Catalog** – Browse perfumes, lotions, and Verseline products with prices, stock levels, and images.
- **Shopping Cart** – Add/remove items, update quantities, and view cart totals.
- **Order Processing** – Place orders with delivery details and payment method selection.
- **Payment Integration** – Supports Cash on Delivery, MTN Mobile Money, and Airtel Money.
- **User Authentication** – Register and login for personalized shopping.
- **Admin Dashboard** – Manage products (add, edit, delete), view recent orders, and update inventory.
- **Image Upload** – Upload product images with auto-compression (max 2MB).
- **Responsive Design** – Optimized for desktop, tablet, and mobile.

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| **Backend** | Flask (Python 3.8+) |
| **Frontend** | HTML5, CSS3, Vanilla JavaScript |
| **Database** | SQLite (development) / PostgreSQL (production) |
| **Payment** | MTN Mobile Money, Airtel Money (simulated) |
| **Hosting** | Render (backend) + GitHub Pages (frontend) |
